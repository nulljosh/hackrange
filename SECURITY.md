# Security

## Reporting

Found something? Email **trommatic@icloud.com**. Don't open a public issue for anything exploitable.

You'll hear back within a week. This is a solo side project. No bounty, no SLA, just a reply.

## Supported versions

The deployed version and the tip of `main`. Nothing else.

## Intended bugs

Juice Shop is broken on purpose and the crackmes are meant to be cracked, so bugs in those are the point. A real report is anything that exposes your machine, like Juice Shop reachable from outside 127.0.0.1.
