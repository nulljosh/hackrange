Hackrange, a pentesting dojo for your Mac

    
Learn to break in on your own machine.

    
A broken web shop to attack and small binaries to crack. It all runs on localhost, with no VM and no Docker.

    

      Start hacking
      Read the source
    

    
Free and open source. Needs a Mac with the Xcode command line tools and Node.

Web pentest
A shop that wants to be robbed
OWASP Juice Shop has over a hundred scored challenges: injection, broken access control, XSS and more. Solve one and its score board ticks it off.

Reverse engineering
Passwords fall out of registers
Small C programs, stripped of symbols. Read the assembly, stop at the compare, and take the secret out of memory.

    

  

  

    
Setup
Nothing to install twice
One script fetches Juice Shop. One script builds the crackmes. The debugger ships with Xcode.

    
Safety
Pinned to loopback
Juice Shop normally listens on your whole network. Hackrange holds it to 127.0.0.1 or refuses to start.

    
Progress
Plain text
Each track keeps a checklist and a spoiler file. Tick things off as you go. Peek only when you are stuck.

  






  

    
Start

    
Four commands in

    
Clone it, start the shop, then open the score board at localhost:3000/#/score-board.

    
$ git clone https://github.com/nulljosh/hackrange
$ cd hackrange
$ ./pentest/run-juiceshop.sh   # the web track
$ ./re/build.sh               # the crackmes

    
One rule

    
Only attack what you own or have written permission to test. Everything here stays on your machine. Pointing these skills at someone else's system without permission is a crime, and it is not what this is for. Read the rules.
